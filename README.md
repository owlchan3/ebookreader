# EBookReader

***演示视频：https://www.bilibili.com/video/BV1ZvhB6DE7g***

一款 Android 本地电子书阅读器。不注册账号、不接入广告，书籍文件、标注笔记与阅读统计全部保存在本机；只有在主动开启 AI 助手或推荐插件时，相关内容才会发送到你自己配置的服务。

支持 EPUB、TXT、DOCX、DOC、MOBI、AZW3 与 PDF，提供书签、划线、批注、离线词典、语音朗读、全书问答与 AI 拆书等能力。


## 一、书籍导入

### 支持的格式

| 格式 | 说明 |
|---|---|
| EPUB | 导入时自动做兼容性修复，详见下文 |
| TXT | 自动识别编码与章节，导入后转为 EPUB |
| DOCX | 提取正文文字 |
| DOC | 提取正文文字 |
| MOBI / AZW / AZW3 | 转换为 EPUB，保留原生章节与图片 |
| PDF | 固定版式阅读 |

### 导入入口

- 书库页右上角「+」，支持一次导入多本书；
- 在文件管理器或其他应用中用「打开方式」选择 EBookReader。

导入过程在书库首格显示进度与「已处理 / 总数」。同一本书不会重复入库：导入前按文件名比对，同批次内也会去重。结束后统一提示「成功导入 N 本，M 本已存在，K 本失败」，失败时附带原因。

导入完成后：按作者建立「相关书籍」关联、在后台生成这本书的关键词。两者都不需要等待，不阻塞阅读。

### TXT 的编码与章节处理

导入时会依次处理：

**编码识别。** 采样文件开头 132 KB，根据结果自动选择编码。

**文本清洗。** 自动去除字节序标记、XML 非法控制字符、私用区字符；识别并删除常见水印行；对成片乱码做滑动窗口检测并整段剔除。

**章节识别。** 内置九类章节标题规则，覆盖 `第一章`/`第 1 章`/`Chapter 1`/`序章`/`楔子`/`番外`/`Part 1`/`Volume 1` 等写法。识别结果过滤：标题到下一个标题之间不足 100 字的视为误判丢弃；识别出超过 30 章时再按关键词白名单过滤，避免把正文里的普通短句当成章节。

**自定义规则。** 内置规则不适用时，可在设置里添加自己的章节正则表达式，输入时即时校验语法。在目录界面长按可手动合并章节。

### EPUB 的兼容性修复

导入时会自动修复：

- 未转义的 `&` 符号导致解析失败；
- `</html>` 之后残留多余内容；
- 多看等阅读器混淆过的文件名（含 `*`、`:`），按清单重命名并同步替换正文中的引用；
- 加密资源：识别到加密清单时跳过并剔除对应资源，而不是整个文件打不开；
- 超大图片降采样，避免翻开就卡死；
- 正文图片补上最大宽高限制，防止图片撑破页面。

### MOBI / AZW3 转换

保留原书章节划分、内联目录超链接、图片与封面。

## 二、书库

**卡片信息。** 书名始终显示；作者非空时才显示；阅读进度显示可在设置页调节。没有封面的书用占位图标。

**排序。** 四种：最近阅读、按书名、按作者、按添加时间。给书打上「置顶」标签后，在「最近阅读」排序下会排在最前。

**搜索。** 模式：

- **文本搜索**——空格分词，多个词之间是「与」关系，匹配书名、作者与格式；
- **标签搜索**——一个专为标签设计的检索框，标签以圆片形式排列，配 “与” 、 “或” 、 “非” 三个运算符和左右括号，允许自由组合。

**命名书架。** 在标签搜索模式下可保存当前标签条件为书架。书架会出现在书库顶部的横向标签栏，点击即展示符合条件的书籍。书架管理页可以查看每个书架包含的标签、删除书架（删除书架不影响标签本身）。

**批量操作。** 长按任意一本书进入多选，顶栏提供全选、批量添加/移除标签、建立关联、删除：

## 三、阅读

### 阅读设置

底部工具栏的「设置」打开阅读设置面板，五项：

| 设置项 | 可选范围 |
|---|---|
| 字体大小 | 0.8 倍至 1.5 倍 |
| 亮度 | 20% 至 100% |
| 主题 | 默认 / 棕褐 / 暗黑 |
| 翻页模式 | 左右翻页 / 上下滚动 |
| 繁简转换 | 原样 / 繁体转简体 / 简体转繁体 |

字号与翻页模式会被记住，下次打开沿用。改变字号时会先记录当前阅读位置，排版重排完成后自动回到原处。

### 界面交互

- 点击屏幕中央显示或隐藏顶栏与底栏，3 秒无操作自动收起（正在拖进度条或打开面板时不收起）；
- 点击屏幕左右边缘翻页，也可以直接上下滑动；
- 界面隐藏时，屏幕左上角显示当前章节名。

### 目录与章节

- 目录按层级缩进，当前章节加粗高亮，打开时自动定位到当前章；
- 点击目录项跳转；
- 长按目录项可以把这一章合并进上一章；
- 目录标题栏的「刷新章节」可以重新识别章节。

后两项针对从 TXT、DOCX 导入的书，因为它们的分章由程序识别得出，可能需要按实际内容调整。章节识别规则更新后，旧书在打开时会自动按新规则重建一次。

### 进度

底部进度条在总页数大于 1 时显示，两端标注当前页与总页数。页码按实际排版结果计算，并按「书 + 字号 + 屏幕宽度」缓存——同一本书换了字号，页数是重新算过的，不是按比例估算。

### 选中的文字能做什么

在正文中长按选中文字后：

- **重排式书籍（EPUB）**：弹出选中浮层，提供复制、分享、划线、批注、词典五项。浮层两端有可拖动的手柄，可以继续扩大或缩小选区；
- **固定版式书籍**：提供复制与分享两项。

### 书籍内搜索

顶部工具栏的搜索按钮打开全文搜索，输入关键词后列出所有命中位置，每条显示「所在章节 + 前文 + 命中词 + 后文」的上下文片段，点击即跳转并定位到该处。

## 四、书签、划线与批注

### 书签

底栏「书签」按钮可以给当前页添加书签，也可以打开书签列表。书签按时间倒序排列，每条可以附加一段笔记，也可以跳转、编辑笔记或删除。

### 划线与批注

选中文字后选择：

- **划线**——给选中的文字加标记，三种样式（高光、底部横线、底部波浪线）× 六种颜色（黄、绿、蓝、粉、橙、紫）；
- **批注**——给选中的文字附加一段笔记，默认使用黄色高光，样式与颜色都可修改。

底栏「批注」按钮打开「批注与划线」面板，分两个页签：有笔记的归入批注，没有笔记的归入划线。每条显示所在页码、原文引用与笔记内容，点击跳转回原文位置，也可以编辑或删除。正文中的标记会实时跟随增删变化。

## 五、语音朗读

朗读面板悬浮在正文之上，可拖动位置，包含上一句、播放/暂停、下一句、停止，也可以收起成一个小胶囊挂在屏幕边缘。

朗读时当前句子会高亮，并自动保持在可见范围内——上下滚动模式平滑滚动过去，左右翻页模式则精确翻到该句所在的页。读到章末会自动接着读下一章。熄屏或切到后台后继续朗读，通知栏提供暂停、继续与停止，点通知回到应用。

朗读引擎有两种方案：

- **系统语音引擎**——使用设备上已安装的语音引擎，可指定具体引擎，可选语速 0.5 至 2.0 倍；
- **云端合成**——接入兼容 OpenAI 接口的语音服务，自行填写地址、密钥、模型与音色。

## 六、离线词典

在正文中选中词语后点「词典」，弹出释义面板。全部词条内置在应用中，查询过程不发任何网络请求。

按查询内容自动分流：中文词查《重编国语辞典修订本》，外文词查 ECDICT 英汉词典。释义面板显示词条、音标、多条释义与例句、备注及来源。

## 七、AI 阅读助手

AI 能力默认关闭，需要在设置中开启「AI 智能助手」并填写自己的接口密钥后使用。这样设计的原因很直接：AI 的调用成本由你直接付给服务商，应用本身不收费、不设配额，书籍内容也不经过我们的服务器。默认使用 DeepSeek，也可以在设置里换成其他兼容 OpenAI 接口的服务。

### 全书问答

从阅读界面进入对话，AI 会先检索整本书的相关内容再作答，而不是只看当前章节。

- **多轮会话**——一本书可以有多个独立对话，左侧抽屉切换、新建或删除；
- **流式回答**——回答逐字显示，可以随时向上翻看历史；
- **思考过程**——使用推理模型时，模型的思考过程单独折叠展示，可展开可收起；
- **书籍内检索**——回答前先在全书范围内检索相关内容，检索期间显示进度提示。

**指定章节提问。** 可以手动勾选若干章节，让 AI 只基于这些章节回答。这种模式下会跳过检索环节，直接把所选章节全文交给模型，适合「只想知道第三章发生了什么」这类问题。

**引入参考书。** 可以从书库中把其他书加进来一起提问，AI 会在所有已加入的书里检索。已经拆过书的书会带标记，并且排在前面。

**导出对话。** 把当前会话导出为纯文本，带书名、创建时间与逐条对话记录，通过系统分享发送出去。

### AI 拆书

从书籍详情页进入。拆书会通读全书并生成结构化的阅读笔记，适合用来快速回顾一部长篇，或者给对话提供更好的上下文。

**书籍类型自动识别。** 先取样开头、中间、结尾与目录，判断这本书属于哪一类，再按类别决定拆解的侧重点。

**逐章摘要。** 每一章输出「梗概」「关键事件」「人物」三段。章节按批次并发处理，每批完成即落盘。

**全书总结。** 汇总各章梗概，生成整本书的主线、人物关系与时间脉络。

| 书籍类型 | 模块 |
|---|---|
| 小说类 | 人物关系、时间线、金句、人物小传、世界观与设定 |
| 历史类 | 历史人物、历史脉络、关键史料、历史人物小传、时代背景与制度 |
| 理科类 | 核心概念/流派、概念递进、公式/定律、学者小传、知识框架 |
| 人文类 | 思想家/学派、论证逻辑、核心观点、思想家、理论体系 |
| 其他 | 核心人物/概念、时间线、金句/要点、人物/主体简介、背景/框架 |

所有类型都包含「拓展阅读」，推荐与本书主题相关的真实作品。

**过程可靠。** 拆书耗时较长，进度在通知栏实时显示，切到后台也会继续。每一批处理完都会保存，中途退出后重新进入可以从断点接着做。单章生成失败会自动重试三次，仍失败时弹窗询问是重试还是跳过，不会整本重来。已经拆完的书再次进入直接展示结果，不重复消耗。

**结果可检索。** 拆书结果页顶部可以搜索，匹配章节标题、梗概、关键事件与人物。右下角悬浮按钮打开目录，快速跳到任意一段。

**结果反哺对话。** 拆过书的书在问答时会同时参考拆书结果，回答的整体性更好。

## 八、书籍详情

从书库点击任意一本书进入详情页。

- **封面**——点击放大查看，可保存到相册，也可以从相册选取新图替换（自动裁剪为合适尺寸）；
- **书籍信息**——书名、作者、格式、文件大小、累计阅读时长、阅读进度；点击编辑可修改书名、作者与简介；
- **标签**——直接点选增删，也可以新建标签；
- **关键词**——展示这本书的关键词词云，词的大小反映权重，点击可查看具体数值；可以手动重新生成；
- **相关书籍**——横向排列的相关书籍卡片。关联有三种来源：按作者自动建立、手动添加、以及屏蔽掉不想看到的自动关联。对自动关联点移除即屏蔽，手动添加的可直接删除；
- **推荐书籍**——开启推荐插件后，这里可以切换到基于本书的推荐结果；
- **AI 功能入口**——开启 AI 插件后，这里出现「AI 拆书」与「AI 生成简介」；
- **更新文件**——替换这本书的书籍文件，标签与阅读时长保留；
- **删除**——二次确认后从书架移除。

## 九、阅读统计

从设置页进入。

- **阅读概览**——藏书数量、总字数、已读字数、整体阅读进度、累计阅读时长；
- **近七天阅读时长**——折线图，点击某一天可以查看当天的阅读时长与当天读得最久的三本书；
- **格式分布**——各类格式各占多少本；
- **热门作者**——按藏书量排出的前五位；
- **最近添加**——最近加入书库的五本书。

阅读时长在离开阅读界面时自动结算并累计，按天记录，也按「每天每本书」分别记录。

## 十、书籍推荐（可选插件）

默认关闭，开启后底部导航会多出「推荐」一项。推荐分两条路：

**基于本机书库。** 分析已读书籍的关键词与作者，结合阅读时长建立一份阅读画像，再按画像从书库中挑出可能想读的书，未读的书会被优先考虑。

**联网搜索。** 从画像中提取主题词去网上找书，可用的来源包括 Google Books、Open Library、豆瓣读书，以及起点、晋江、菠萝包三个书源。Pixiv 小说需要单独填写登录凭据后启用。综合来源可信度、评分、简介完整度与热度排序后呈现。

推荐的每张卡片都有「不感兴趣」，点掉之后不会再出现。设置里可以配置偏好题材（可加权，也可以填负数表示排除）、Google Books 密钥、Pixiv 凭据，以及清空不感兴趣记录。

**单本推荐。** 详情页也可以针对某一本书单独找书，综合这本书的标签、作者、书名、简介关键词与正文关键词进行搜索。

## 十一、数据管理

设置页的「数据管理」提供七项：

- **书籍统计**——跳转阅读统计页；
- **存储详情**——分别列出书籍文件、封面、检索索引、拆书结果、聊天记录与数据库各占多少空间，附文件数、书架本数与按扩展名的明细；
- **清理存储**——删除书籍目录下已不再被引用的文件；
- **删除某本书的索引**——逐本列出检索索引占用，可单独清掉；
- **清空全部索引**——二次确认后清空；
- **导出备份**——打包为一个压缩包，含数据库、书籍文件、封面与全部设置；
- **导入备份**——选择备份包恢复，完成后应用自动重启。

## 十二、已知限制

- **CBZ 暂不支持。** 漫画格式尚未接入，后续会评估适配成本。
- **PDF 是固定版式。** 可以正常阅读与翻页，但重排、标注、字号调节这些针对流式排版的能力不适用。
- **自定义字体、行距、段距、页边距暂未提供。** 目前可调的是字号与亮度。
- **标注暂不支持导出。** 书签、划线与批注目前只能在应用内查看，导出为 Markdown 等通用格式的能力在计划中。
- **云端同步暂未提供。** 换设备目前依靠整库备份与恢复。
- **AI 功能需要自备接口密钥。** 这是为了保持应用完全免费且不经过第三方服务器，代价是需要用户自行配置。
- **联网书源依赖第三方服务。** Google Books、豆瓣、Pixiv 等的可用性受对方服务与政策影响，可能随时变化。
